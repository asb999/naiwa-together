# 隐私说明

当前版本的面部与手势分析在浏览器中执行。代码只请求视频，不请求麦克风，没有实现录像、远程保存视频、上传人脸特征或统计观众行为的功能。

需要联网加载的服务包括 Tailwind CSS、Google Fonts、jsDelivr 的 MediaPipe 程序及相关文件、Google 托管的识别模型，以及默认笑声音频所在的 jsDelivr / Myinstants。请求这些服务会产生常规网络连接信息。浏览器语音由系统提供，联网与否取决于所选声音。

用户选择的本地图像和音频保存在浏览器 IndexedDB 中。当前代码不会主动上传这些文件。换浏览器、换设备、清除站点数据或使用隐私浏览模式后，素材可能不再可用。

素材面板的“恢复默认配置”会尝试删除本地素材数据库并刷新页面。若未成功，可通过浏览器的站点数据设置清除。关闭页面，或在浏览器权限设置中撤销摄像头权限，可以结束摄像头使用。

请在同伴知情同意后共同出镜。项目没有实现录制或分享影像的功能。
