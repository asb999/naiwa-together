# 奶蛙同乐 · Naiwa Together

让一个人的笑，变成一群人的快乐。

一个来自灵感工作坊的浏览器音画互动实验。面对摄像头，独自或与朋友一起大笑、举手、比心，屏幕中的奶蛙就会用贴纸、动画和声音回应。作品希望让人像日常聊天、看视频一样轻松开心，也让互动成为人与人连接的起点。

## 作品缘起

最初的想法来自阅读《音乐与生命》、听到作者讨论，以及日常观看抽象奶蛙内容的体验：如果把熟悉的表情包放进身体互动里，朋友之间能否多一点共同的笑声？工作坊中的声音互动作品进一步启发了音效回应。

当前公开版本保留工作坊原型，没有加入新的诗句关卡。创作过程使用 Gemini 辅助生成与迭代代码；聊天中的“已经修好”“已找到真实原声”等表述并不视为经过验证的事实。

## 当前可以做什么

| 观众的动作 | 画面回应 |
| --- | --- |
| 张嘴微笑 | 单蛙捧腹大笑 |
| 两人或更多人同时张嘴微笑 | 双蛙共同大笑 |
| 双手靠近画面下部 | 捧腹大笑 |
| 双手举高并分开 | 飞天开心 |
| 面部表情平静约两秒 | 呆滞凝视 |
| 点赞、双手比心 | 点赞、爱心贴纸 |
| 两只手快速靠近 | 清空贴纸 |

表情和手势只是画面特征判断，不能推断真实情绪。最多配置四张脸、四只手；多人动作可能互相干扰，不是身份识别或好友匹配。

还可以在素材面板预览贴纸、分别替换图片和音效，或批量拖入文件。导入素材保存在当前浏览器中，清除浏览器数据会丢失，不能理解为永久保存。

## 本地体验

最简单的方式：下载本仓库，双击 `index.html`，或用浏览器打开这个文件即可体验，不需要安装 Python。点击开启按钮，并按浏览器提示允许使用摄像头。需要联网加载识别模型等资源。

如果直接打开时遇到摄像头权限或资源加载限制，可以使用下面的本地启动方式（需要 Python 3）。进入本目录运行：

```sh
python -m http.server 8000 --bind 127.0.0.1
```

打开 http://localhost:8000 ，点击开启按钮并允许摄像头。建议使用桌面版 Chrome 或 Edge。直接打开本地文件时的摄像头访问取决于浏览器及其安全设置；若通过网站访问，请使用 HTTPS 或 localhost。浏览器可能需要额外点击才允许播放声音；首次启动需要下载外部模型，网络受限时可能无法开始。当前版本不支持完全离线使用。

## 隐私与素材

程序仅申请摄像头，不申请麦克风；当前代码没有录像、拍照上传或分析结果上传功能。字体、样式、识别模型和默认笑声音频需要向外部服务请求；浏览器语音使用系统提供的声音，是否涉及联网取决于系统和声音提供方。详见 [隐私说明](docs/PRIVACY.md)。

代码授权和角色、表情包、音效授权是两件事。当前图形是原型中内嵌的参考形象绘制，不能保证与现有角色无权利关联；外链音效未核实再分发许可，也不能保证它们就是参考视频中的原声。详见 [素材与授权边界](THIRD_PARTY_NOTICES.md)。本仓库不包含原始聊天、私人笔记、参考图片或下载的第三方音频。

## 已知限制与参与方式

- 动作判断比较粗略，光线、取景和多人站位会影响结果。
- 默认音效依赖外链，可能失效；“豆包”只是原型里的声音模式名称，并未接入豆包官方服务，也不保证相同音色。
- 原型静音按钮不能保证立即停止已经开始的音效；声音模式切换也存在外链笑声优先播放的问题。
- GitHub Pages 尚未配置。本地界面、程序语法及摄像头体验的实际检查结果见 [检查记录](docs/VERIFICATION.md)。

欢迎提交问题或改进建议，尤其是识别稳定性、声音控制、可替换的原创角色、无摄像头体验和诗句叙事。请勿提交密钥、私人聊天、未获同意的人像录像或授权不明的素材。
